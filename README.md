# Wilson Bolsas

> **This project was 100% generated by AI (Claude Sonnet 4.6) as a vibe coding experiment.**
> Not a single line of code was written by the human developer.
> The goal is to evaluate Claude's capabilities in building a complete Flutter app from scratch, with zero human intervention in the code.

---

## About the app

**Wilson Bolsas** is a stock manager for a purse/bag store. The app allows:

- Registering **purse models** with a selling price
- Registering **materials** (leather, zipper, thread, etc.) with a price per unit
- Building a **bill of materials (BOM)** for each model, specifying which materials are used and in what quantity
- **Automatically calculating** the production cost and profit per unit
- **Managing stock** with inbound and outbound movements
- Viewing a **dashboard** with a financial summary, low-stock alerts, and the most profitable model

All data is stored **locally** on the device via SQLite — no internet, no backend.

| Layer | Technology |

| Database | sqflite (local SQLite) |
| State management | provider (ChangeNotifier) |
| Navigation | go_router (ShellRoute + declarative routes) |

## How to run

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. Clone the repository
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
